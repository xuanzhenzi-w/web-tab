隐私权政策

最后更新：2026 年 8 月 19 日

本隐私权政策说明标签管家 Tab Manager（以下简称「本扩展」）如何收集、使用和保护您的数据。安装或使用本扩展即表示您同意本政策。

一、我们收集哪些数据

本扩展仅在您的本地浏览器内处理以下数据，不会传输至任何远程服务器：

数据类型用途存储位置
标签页 URL去重检测（判断相同链接是否已打开）、归档记录（关闭后可恢复）chrome.storage.local（本地）
标签页标题归档记录展示与搜索chrome.storage.local（本地）
标签页图标（favicon URL）归档列表中的视觉标识chrome.storage.local（本地）
用户设置偏好去重开关、自动归档开关、闲置时长阈值、固定标签保护策略、界面语言选择chrome.storage.local（本地）
标签最后访问时间自动归档功能判定标签是否超时闲置chrome.storage.session（本地，会话级）

二、数据如何使用

  • 同链接去重：读取当前所有标签的 URL，与新打开的 URL 比对。若发现完全相同的链接，切换到已有标签而非新建。
  • 同域名合并群组：读取标签 URL 的域名部分，将同一窗口内同域名的标签收进同一标签群组并设置标题和颜色。
  • 自动归档：每分钟巡检一次所有标签的最后访问时间，超过用户设定时长未访问的非激活标签将被关闭，其元数据（URL、标题、图标、时间）存入归档列表。
  • 手动归档：用户主动触发时，记录所有窗口中所有标签的元数据后关闭。
  • 归档恢复/删除：用户可在归档页面查看历史记录，选择重新打开原始 URL 或删除记录。

三、数据共享与传输

本扩展不会将任何用户数据发送至第三方服务器、云端服务或任何外部方。 所有数据处理均在您的浏览器本地完成。

本扩展：

  • ❌ 不包含任何网络请求代码（无 fetch、XMLHttpRequest、WebSocket）
  • ❌ 不使用任何分析工具或追踪 SDK
  • ❌ 不嵌入任何第三方脚本或广告
  • ❌ 不连接任何远程服务器

四、数据存储与安全

所有数据通过 Chrome 扩展 API chrome.storage.local 和 chrome.storage.session 存储在您的设备本地。这些数据：

  • 随您的 Chrome 用户配置文件同步（如果您开启了 Chrome 同步功能）
  • 卸载扩展后可通过 Chrome 设置清除残留数据
  • 不会被本扩展的开发者或其他任何方访问

五、用户权利

  • 导出/清除数据：您可以在扩展的选项页面重置所有设置，或在归档页面清空所有归档记录。
  • 卸载：通过 Chrome 扩展管理页面 (chrome://extensions/) 卸载本扩展即可停止所有数据处理。
  • Chrome 数据控制：您可以通过 Chrome 设置 → 隐私和安全 → 网站设置 → 查看权和站点数据来管理和清除扩展存储的数据。

六、未成年人使用

本扩展不针对未成年人设计，也不故意收集未成年人的个人信息。

七、政策更新

我们可能不时更新本隐私权政策。如有重大变更，我们会通过扩展商店页面发布通知。建议您定期查阅本页面。

八、联系我们

如您对本隐私权政策有任何疑问，请通过 Chrome Web Store 本扩展的「联系开发者」渠道与我们联系。

九、捐赠支持

本扩展完全免费，不向您收取任何费用，也不包含任何付费墙或应用内购买。若您愿意自愿支持开发，可在设置页通过外部链接前往第三方平台（爱发电）进行捐赠。

  • 捐赠行为完全在第三方平台完成，本扩展不收集、不传输、也不接触任何支付信息（如银行卡号、密码等）。
